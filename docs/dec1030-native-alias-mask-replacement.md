# DEC-1030 — Mask replacement via duplicate hides source writes while preserving WD number

**DRAFT / NEVER MERGE / NEVER PROMOTE.** Strict one-commit disposable-public Linux regression/documentation child of DEC-1029/#1250.

An existing native original source+parent inotify instance is duplicated using `os.dup`. A *separate* real inotify instance provides a genuine independent control. Calling `inotify_add_watch(duplicate_fd, sample, IN_OPEN | IN_DONT_FOLLOW)` **without `IN_MASK_ADD`** replaces the original instance's source subscription mask with an `IN_OPEN`-only mask, yet **returns the same source WD number**. A genuine distinct-byte source write during this mask gap yields native original source `IN_OPEN` and parent named `IN_MODIFY`/`IN_CLOSE_WRITE`, but **no original source-WD `IN_MODIFY` or `IN_CLOSE_WRITE`**. The untouched independent dual watcher still sees real source and parent write records.

The original unchanged parser fails closed on unexpected native `IN_OPEN` (`well_formed=false`), and the evaluator stays `BLOCKED`, exact `can_authorize_dispatch=false`, `independent_os_proof_verified=false`. Restoring `module.MASK | IN_DONT_FOLLOW` via the original FD also returns the **same WD**, produces **no retroactive source events** for the missing interval, but a later real byte restoration is seen on source+parent native WDs. The original sample and parent device/inode/mode, restored public bytes, one-entry inventory and all native FD closures are checked.

A separate Linux probe on a new disposable `/tmp` source verified unchanged WD numbers, an `IN_OPEN`-only source record during genuine bytes modification, named parent write records, independently observed full source writes, and restored source mask for a later write. Contrasts with DEC-1025/#1246, which ADDS `IN_OPEN` without losing existing source `IN_MODIFY` events. Adds one Linux source-defined method, bringing the draft stack to **674**.

Neither unchanged WD numbers nor restored final bytes prove uninterrupted provenance or independently OS-enforced protected no-write.
