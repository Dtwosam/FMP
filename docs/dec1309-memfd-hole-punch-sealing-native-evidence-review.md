## Required invariants for reviewers

These memfd probes are not normal original named-path tests. `memfd_create(MFD_ALLOW_SEALING)` creates a fresh **anonymous** inode; each test watches its own inode via an independent native `inotify_add_watch("/proc/self/fd/<memfd>")` and tests raw `IN_MODIFY`, final `IN_DELETE_SELF` and `IN_IGNORED`. There is **no named original parent**, and claims of source+named-parent watcher coverage or the named-source helper `_evaluate` must not be transplanted to these anonymous objects. Exact `F_GET_SEALS` states, syscall return values/errno, original memfd `pread` bytes, size, real mmap backing changes, cleanup and quiet/positive native event buffers form the inspectable native provenance.

**Local watcher silence cannot establish OS-enforced no-write.** The stronger sealing combinations genuinely reject the tested operations **on their own anonymous memfd**, and the weaker combinations expose data-loss paths. But applying a seal to an anonymous test object is not proof that existing protected annual filesystem sources are under any independent OS-enforced rule or have immutable exclusive admission. The named-source kernel tests from earlier drafts and these anonymous tests are deliberately separate evidence classes.
