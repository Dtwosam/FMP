On a freshly created generated PUBLIC ordinary source, a genuine Linux `os.open(O_RDONLY)` **without O_TRUNC** produces a positive independently watched source **IN_OPEN**, but no source or named-parent mutation. Two real `os.ftruncate(readonly_fd, size)` calls are then attempted: first to zero (which would destroy the file if allowed), and then to the file's existing length (which on a writable FD would itself emit MODIFY under DEC-1209). The executable regression allows native EBADF or EINVAL rejection, and separately requires source/parent mutation queues to remain empty. Closing the read-only FD produces a real independently watched **IN_CLOSE_NOWRITE**, not CLOSE_WRITE.
