## Integrity and evidence separation

Actual changed/restored original file states remain **BLOCKED** and no positive independent OS no-write authorization is claimed.

Read-only file handles, a failed mmap, unchanged PRIVATE copy-on-write mapped memory, `MADV_DONTNEED` visible refault or absent `IN_ACCESS`/IN_MODIFY evidence cannot be taken as proof of an immutable original file. The **original inode's content** and the **userspace mapping's current bytes** are not interchangeable. Genuine original-file writes can be observed by active original source+parent native inotify, but memory-mapped writes, reads and mapping changes can remain event quiet. No local watcher diagnostic enforces denial.
