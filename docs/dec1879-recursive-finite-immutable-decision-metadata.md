Previously the Phase3 BacktestConfig held a top-level read-only decision_config mapping containing mutable nested dictionaries/lists. DEC-1878 deep-copied those nested structures from the caller, but a later write through the retained config could still alter the reported run identity. That was not a permanent provenance boundary. This fails closed for NaN/Infinity, custom opaque objects, non-string nested keys and cycles without invoking arbitrary `__deepcopy__` code. The run-identity renderer recursively materializes fresh ordinary dict/list values to preserve its output schema; changing the result of one rendering cannot change subsequent renderings.
