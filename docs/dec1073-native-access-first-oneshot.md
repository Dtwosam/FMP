# DEC-1073 — Read ACCESS without OPEN registration disarms source one-shot before later writes

**DRAFT / NEVER MERGE / NEVER PROMOTE.** Strict one-commit child of DEC-1072/#1293 at `1a1b7c034d6afcad7abd21067ceebb555edaf56a`. One generated-public Linux native regression and one Markdown document; **702 source-defined tests**. No runtime or production changes.

An independently registered source-only watcher subscribes to `IN_ACCESS | IN_MODIFY | IN_CLOSE_WRITE | IN_ONESHOT | IN_DONT_FOLLOW` but deliberately **does not subscribe to IN_OPEN**. A genuine read-only open is shown to leave that source one-shot's queue quiet; the first successful read of the disposable PUBLIC source produces an unnamed `IN_ACCESS` event followed by native `IN_IGNORED`, with no content or metadata mutation. A completely separate continuous native source+parent inotify instance remains quiet for this harmless read.

A later genuine changed-byte write and writable close to the very same source are invisible to the disarmed one-shot **despite both mutation masks being present**. The independent watcher records actual source `IN_MODIFY` and `IN_CLOSE_WRITE` plus named parent `IN_MODIFY` and `IN_CLOSE_WRITE`. Another real write restores original public bytes but is still invisible to the removed one-shot and witnessed independently. Unchanged evaluator returns exactly `BLOCKED`, `can_authorize_dispatch=false`, `independent_os_proof_verified=false` for both witnessed writes; equal final bytes never authorize.

Unlike DEC-1069/#1290, this observation does **not** depend on a subscribed OPEN event: non-mutating data access itself is sufficient to destroy an `IN_ONESHOT` subscription before later mutation. Native probe on disposable Linux `/tmp` files confirmed OPEN had no queued event, followed by ACCESS→IGNORED on actual reading and later independently witnessed MODIFY/CLOSE_WRITE activity. The executable test asserts source+parent dev/inode/mode, original bytes, bounded one-entry inventory, and FD closure.

This test installs a deliberately alternative one-shot mask; existing `scripts/dec677_disposable_inotify_events.py::_start_watch` is **not** modified and does **not** use IN_ONESHOT.
