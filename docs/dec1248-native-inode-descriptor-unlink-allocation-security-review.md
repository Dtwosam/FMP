## Threat and review boundaries

**Original filename absence**, **empty directory inventory**, **read-only descriptor**, **O_APPEND**, **a successful close call**, **a failed later syscall**, **unchanged file digest**, and **unchanged file length** each fail as stand-alone claims that a source was immutable. Actual native behavior may depend on Linux kernel and filesystem. Preserve *temporal* observations and true source-inode/parent watch identity: a last-link-unlinked but open descriptor can still mutate original bytes after its filename disappeared, and a duplicated descriptor can prolong that exposure after another FD has closed. Linux may still emit **named parent events for the removed file's dentry** until final reference release. The test-only source ONESHOT is deliberately unsafe, expiring on its first genuine MODIFY→IGNORED; the unchanged actual continuous two-watch helper remains active through all subsequent observable operations until Linux genuinely invalidates the source inode watch.

Every test verifies real `inotify` event-buffer bytes and accurate generated PUBLIC snapshots with unchanged `scripts/dec677_disposable_inotify_events.py::_evaluate`: **status=BLOCKED**, **can_authorize_dispatch=false**, **independent_os_proof_verified=false**. Detection and diagnosis of failure modes are NOT proof of independent OS-enforced access denial or permission to promote. Source names and metadata may be restored for disposable tests except intentional last-link deletion cases, which verify final irreversible disposable inode retirement and never claim old inode restoration.
