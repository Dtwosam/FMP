**DRAFT / NEVER MERGE / NEVER PROMOTE.** Strict one-commit disposable Linux test/documentation child of DEC-998/#1219.

DEC-998 swaps two symlink *inodes* whose targets are the same public source. DEC-999 instead starts with two generated **different regular-file inodes**, original `sample` and `public-other`, and two distinct symlinks pointing separately to each target. The original source+parent inotify watches remain live while a third genuine WD subscribes to the other regular-file inode. A real native `renameat2(RENAME_EXCHANGE)` atomically swaps the symlink pathnames; the parent reports two matched, nonzero rename-cookie pairs.

The original sample WD is quiet for that write, and an unmodified two-WD parser rejects the third WD rather than treating it as an authorized quiet source interval. A subsequent write through the *second* alias reaches the original `sample` inode, generating genuine original source `IN_MODIFY` and parent named `sample` write records; the unchanged evaluator returns `BLOCKED`, with `can_authorize_dispatch=false` and `independent_os_proof_verified=false` exactly. Both public regular-file contents are restored through the exchanged aliases, the temporary aliases and other file are removed, and original source/parent dev, inode, mode, inventory and FD closure are verified.
