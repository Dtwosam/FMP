# DEC-1003 — Atomic directory exchange preserves watched inodes and emits IN_ISDIR

Two *directories* created within a private `/tmp` parent are registered on separate native inotify WDs (`IN_MOVE_SELF | IN_DELETE_SELF | IN_ONLYDIR`) alongside the unchanged source+parent watch pair. Native `renameat2(RENAME_EXCHANGE)` atomically swaps the two directory entry pathnames. The kernel emits **two matched nonzero rename-cookie pairs** with `IN_MOVED_FROM | IN_ISDIR` and `IN_MOVED_TO | IN_ISDIR` on the parent, and `IN_MOVE_SELF` separately on both moved directory WDs, preserving their watched inode identity.
