# Phase 8A EXP-066 Temporal State-Transition Research Direction

**Decision:** DEC-469  
**Experiment:** EXP-20261002-066  
**Status:** SOURCE-ONLY RESEARCH DIRECTION / EXECUTION LOCKED  
**Governing method:** DEC-268 discovery-first market-pattern research  
**Current sub-experiment:** bounded temporal state-transition discovery

## Purpose

DEC-468 froze EXP-065 as a negative result for its exact pairwise continuous-feature interaction representation: 13,680 of 13,680 hypotheses were evaluable and none qualified. That result closes the exact EXP-065 family but does not reject the governing discovery-first method.

DEC-469 opens only the next source-design question: **does the path into a market state matter?**

The intended representation is a same-dimension prior-state -> current-state transition using the already accepted leakage-safe market measurement vocabulary. Examples of the behavioural class include volatility compression -> expansion, momentum-state change, trend-state change, location-state change, spread-state change, and session-state transition. Exact states, transition lags, search volume, support thresholds, economic gates, chronology, and freeze rules must be frozen in the next protocol decision before any historical execution can be considered.

## Mandatory guardrail mapping

1. **Market behaviour intended to discover.** Whether the temporal path into a current leakage-safe market state carries repeatable information about fixed future outcomes, rather than treating the current state as a sufficient snapshot.

2. **DEC-268 measurement vocabulary covered.** The successor may use the existing accepted dimensions for direction/trend, sideways/range, volatility and volatility change, momentum and return structure, candle/range structure, session/time context, location relative to recent/session structure, spread/quote quality, and fixed future return or price-path outcomes.

3. **Deliberate omissions.** DEC-469 does not authorize cross-dimension transition interactions, sequences longer than prior-state -> current-state, three-plus-feature combinations, new raw features, new symbols, new timeframes, new outcome horizons, alternative data, clustering/model-family search, or any use of the 2023-2026 reserve.

4. **Why this is useful after prior evidence.** EXP-065 asked whether two simultaneous continuous features had incremental static interaction information after controlling their main effects. EXP-066 asks a different behavioural question: whether how the market arrived at a state matters. It is not an EXP-065 threshold relaxation, protocol rewrite, or hypothesis rescue.

5. **Meaning of a negative result.** If a later frozen EXP-066 protocol produces no survivors, that would reject only the exact frozen same-dimension temporal-transition representation and protocol.

6. **What a negative result would not mean.** It would not reject DEC-268 discovery-first market learning, prove no market edge exists, or exhaust cross-dimension, longer-sequence, different-state, statistical/model, or future prospective representations.

7. **How a survivor rejoins the main workflow.** Any survivor is only a pattern hypothesis. It must be frozen and pass later chronological confirmation/validation without redesign. Only after that may a separate decision compile it into exact strategy/model semantics, run robustness/backtest gates, and eventually seek prospective shadow/demo evidence.
