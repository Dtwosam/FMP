# DEC-1006 — Mixed regular-file and directory atomic exchange preserves inode watches

**DRAFT / NEVER MERGE / NEVER PROMOTE.** Strict one-commit child of DEC-1005/#1226. Native Linux test and documentation only.

Existing controls separately swap symlinks (DEC-998) or two directories (DEC-1003). This generated-public control performs actual `renameat2(RENAME_EXCHANGE)` between the original **watched regular file `sample`** and a separate watched empty **directory `public-other-dir`** in a private disposable `/tmp` fixture. The first swap makes `sample` name a directory and `public-other-dir` name the original source file, without changing either watched inode or WD. The second swap reverses those pathname types and restores both inode locations. Neither watched inode is invalidated by either rename.

Each genuine kernel exchange emits two distinct nonzero rename-cookie pairs, one with regular-file `IN_MOVED_FROM`/`IN_MOVED_TO` and one with `IN_MOVED_FROM | IN_ISDIR`/`IN_MOVED_TO | IN_ISDIR`, plus `IN_MOVE_SELF` on BOTH the source-file WD and separate directory WD. The test verifies the cookie pair identity, type modifiers, both inode values and their correct pathname changes; it feeds the **complete actual native stream** to the original two-WD parser and unchanged evaluator. An unexpected third WD must fail closed: `well_formed=false`, `status=BLOCKED`, `can_authorize_dispatch=false`, `independent_os_proof_verified=false`.

After swapping back, the disposable directory is removed, generating genuine `IN_DELETE | IN_ISDIR`, directory `IN_DELETE_SELF` and `IN_IGNORED`. The original regular-file source/parent watchers still detect real changed-byte writes and restoration. Final original source+parent dev/inode/mode, public bytes, one-name inventory and native FD closure are asserted.
