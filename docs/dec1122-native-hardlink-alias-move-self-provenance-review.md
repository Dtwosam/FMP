**Inference boundary:** Linux inotify's IN_MOVE_SELF is a genuine notification about a **watched inode whose directory entry was renamed**, not proof that the particular pathname passed to `inotify_add_watch` stopped resolving. A different hard-link alias of the *same* watched inode can be renamed and still cause source IN_MOVE_SELF while the original `sample` name remains present. The event is not evidence of a content write. The directory event stream identifies the **renamed pathname**, and only for entries inside that specific watched directory. In the external alias case, the original parent has no rename event, although a continuing source watch still sees IN_MOVE_SELF.

All three cases use independent native Linux watches on disposable PUBLIC files. The original deliberately unsafe source-only `IN_MOVE_SELF|IN_MODIFY|IN_CLOSE_WRITE|IN_ONESHOT` expires after its first matching event and reports IN_IGNORED. It cannot later witness genuinely changed-byte/restoring source writes. An **independent continuing** full source+parent observer captures actual source and named-parent MODIFY/CLOSE_WRITE for later `sample` writes. The unchanged parser marks original native source MOVE_SELF receipts as invalidated, and the unchanged evaluator returns `status=BLOCKED`, `can_authorize_dispatch=false`, and `independent_os_proof_verified=false`, even if path and bytes are restored or never ceased to resolve.

**Do not conflate watch lifetime with immutable-security evidence:** The helper `scripts/dec677_disposable_inotify_events.py::_start_watch` is unchanged; it actually installs continuing native source+parent watches **without IN_ONESHOT**. These deliberately unsafe alternatives are used only in generated-PUBLIC regressions. Their native events neither show an installed defect nor independently OS-enforce protected annual no-write or admit annual dispatch. For alias cases, sample has nlink=2 during the experiment; the actual snapshot helper separately rejects multi-linked source inodes in any admissible clean snapshot. A final same dev/ino/mode/nlink and byte digest cannot reconstruct intervening events.
