The kernel one-shot guarantee is **trigger once on the first matching event** and auto-remove the watch, emitting `IN_IGNORED`. It is not a promise to observe every action named in its registration mask. A quiet buffer before a matching event, a quiet buffer after watch removal, and a true absence of filesystem activity are different propositions. A final byte-for-byte restored sample, restored metadata mode, or returned one-entry namespace inventory can coexist with real intermediate write, chmod, mkdir and rmdir actions. A regenerated sibling directory with the same name is NOT proof it retained an earlier inode.

All experiments operate only on new disposable PUBLIC `/tmp` files using real Linux inotify events, original source and parent watches or separate native one-shot instances. Independent observers are **distinct inotify instances**, not `dup()` aliases. Every new regression checks original sample bytes, source+parent dev/inode/mode, inventory, FD closure and the native mask/name identities. Separate disposable Linux kernel probes confirmed the create-first and delete-first combined-mask directory lifecycles and both source content/metadata first-match orderings.
