Genuine `libc.fallocate(fd,FALLOC_FL_KEEP_SIZE,0,4096)` on a fresh PUBLIC O_WRONLY source reserves filesystem allocation space without extending its **logical length** or changing its **existing data bytes**. On the probed Linux kernel, it emits real **unnamed source IN_MODIFY** and **named original-parent IN_MODIFY(sample)**. A separately installed deliberately unsafe **source IN_MODIFY|IN_CLOSE_WRITE|IN_ONESHOT** is removed as **IN_MODIFY→IN_IGNORED** on that first allocation event. The unchanged continuing source+parent mutation helper receives the real event receipts; its unchanged evaluator receives the true native stream with **(BEFORE,BEFORE)** data snapshots and returns exactly **status=BLOCKED, can_authorize_dispatch=false, independent_os_proof_verified=false**.

The test verifies the source data bytes and logical length truly remain unchanged, and that `st_blocks` does not decrease. The genuine O_WRONLY close independently generates continuing source+named-parent CLOSE_WRITE. Separate later actual changed-byte and restoring source writes produce positive continuing source+parent MODIFY/CLOSE_WRITE even after original one-shot removal. Original/restored PUBLIC bytes, inode/mode/link identity, directory inventory and fd cleanup remain checked. If the disposable filesystem explicitly does not support KEEP_SIZE fallocate (EOPNOTSUPP/ENOSYS/EINVAL), this specific regression skips on that host rather than asserting an unsupported syscall succeeded.

A standalone native Linux syscall probe on freshly generated PUBLIC /tmp files confirmed KEEP_SIZE mode (0x01) succeeded and returned **source+parent MODIFY with unchanged bytes**, original unsafe one-shot removed, and normal source+parent CLOSE_WRITE on later descriptor close. Unlike #1398 same-length ftruncate, this operation concerns **disk extent preallocation**, not file length adjustment. An IN_MODIFY receipt must not be treated as proof of changed source bytes, while a quiet native queue must not be used as OS-enforced protected no-write proof (mmap can change data without immediate MODIFY).
