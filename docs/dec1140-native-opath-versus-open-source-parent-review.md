**Identity and timing are central.** A Linux `O_PATH` handle is a path-only reference: no normal read-side IN_OPEN or IN_CLOSE_NOWRITE is emitted merely by opening or closing it. A normal O_RDONLY **source-file** open emits unnamed source IN_OPEN, and its later close emits IN_CLOSE_NOWRITE on a separately subscribed **continuing read watcher**. The normal source+parent mutation helper does not subscribe to either. A real **parent-directory scan** emits IN_OPEN with **IN_ISDIR** on its parent inode, not a named child-file IN_OPEN. The original alternative one-shot is consumed by the first subscribed read OPEN, even before its descriptor would be closed.

**Do not conflate quiet O_PATH with authorization.** O_PATH does not, by itself, report a content write, and a quiet inotify read-event stream is **not** an OS-enforced protected no-write policy, an independent annual proof, or evidence that later operations were harmless. In each disposable one-shot negative test, the original unsafe registration fails to capture later genuine source modifications **because it was removed**. The actual unchanged independently initialized **continuing source+parent** helper positively captures subsequent genuine changed-byte and byte-restoring writes: unnamed source MODIFY/CLOSE_WRITE plus named parent MODIFY/CLOSE_WRITE(sample). The unchanged evaluator returns `status=BLOCKED`, `can_authorize_dispatch=false` and `independent_os_proof_verified=false`, even after original bytes are restored.

**Avoid verification-induced read events.** A test subscribing to native source IN_OPEN/CLOSE_NOWRITE must drain and close its separate read witness before calling `sample.read_bytes()`, which would otherwise generate more real read-side events. DEC-1138 explicitly does so. A test subscribing to parent IN_OPEN must conduct pre-watch inventory checks **before registering** the original one-shot, because the helper's own `os.scandir` can consume that alternative watch. DEC-1139 confirms O_PATH itself leaves the original parent watch active until the intentional scan. No assertion about fully unchanged atime/ctime/mtime is implied; mount-specific metadata behavior remains outside these byte-value controls.

All observations are real native Linux syscalls on newly generated disposable PUBLIC /tmp files. The alternative IN_ONESHOT masks are deliberately unsafe **test-only registrations**, not an installed defect. Actual unchanged `scripts/dec677_disposable_inotify_events.py::_start_watch` uses continuing source+parent mutation watches **without ONESHOT**. No modification to executable helper or protected annual runner is made here.
