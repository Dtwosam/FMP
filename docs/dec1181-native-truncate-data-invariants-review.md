**Do not substitute one signal for another.** Event mask, actual transferred bytes, snapshot content, inode identity, link count, file size, write access, and descriptor lifetime are separate evidence dimensions. A no-op `ftruncate` yields MODIFY without a content delta; a mapped write can create a content delta without immediate MODIFY; shrinking then growing restores length while destroying original bytes. Neither a quiet interim event queue nor a restored size provides independently OS-enforced protected annual no-write proof.
