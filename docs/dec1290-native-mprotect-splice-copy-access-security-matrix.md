## Evidence provenance and limits

Every executable regression registers the genuine original source inode and original named-parent native inotify watches through unchanged `scripts/dec677_disposable_inotify_events.py::_start_watch`. Tests that distinguish read from write register a **separate independent Linux IN_ACCESS observer**, not merely infer reading from unchanged file bytes. All native event buffers are decoded and independently drained with exact Linux watch descriptor identity, action mask and original/destination names. The original **source MODIFY|CLOSE_WRITE|IN_ONESHOT** watcher is intentionally **unsafe and only test-only**: it expires on the first true source modification but remains armed through pure source reads, private COW memory writes and denied mprotect upgrades. The real continuous helper sees eligible later kernel receipts; neither watcher enforces access restrictions.

Actual **original PUBLIC source bytes** and mapping/pipe/destination bytes are checked independently. A private mapping can show different memory while its original inode is unchanged; a source-to-destination file copy can emit named MODIFY of destination while original source is only read; a pipe→source splice genuinely changes original inode even without Python `os.write` or `os.pwrite`. An O_RDONLY mprotect EACCES is a real narrow access rejection but does not prevent independent original-source write access. Conversely a succeeded MAP_PRIVATE mprotect write upgrade grants COW memory mutation, not original source overwrite.

On all actual source-changing/restoring operations, unchanged `_evaluate` remains **status=BLOCKED**, **can_authorize_dispatch=false**, **independent_os_proof_verified=false**. Quiet reads/failed operations are also **nonauthorizing**. Local native evidence cannot be promoted into independently OS-enforced protected no-write or immutable annual admission.
